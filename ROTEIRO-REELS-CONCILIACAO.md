## POR QUE ESTE TEMA, E NÃO ESTOQUE

A página `auditoria-inventario-drone-agentes.html` vende "100% on-host · zero dado
à nuvem · o dado do cliente nunca sai do ambiente". Citar um motor de decisão
hospedado em API de terceiro num reel de inventário contradiz essa promessa.

Conciliação bancária não carrega essa restrição, e a natureza do trabalho — milhares
de lançamentos, cada um exigindo um veredito de "casa ou não casa" — é o caso de uso
mais direto que existe para decisão tipada.

**Condição para publicar:** só grave este reel se a conciliação com apoio automatizado
já for um serviço que a AUDIPER de fato presta. Reel não é lançamento de produto.
